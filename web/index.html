使用说明

  

    
第一次使用

      
  1. 启动软件后会自动探测显卡、创建独立虚拟环境，并下载匹配的 PyTorch / Ultralytics 与默认权重。
    2. 
      
  2. 「数据集」页新建数据集，或挂载已有的 YOLO 目录。
    3. 
      
  3. 「打标签」页人工画框；点「AI 预标注」可用已有权重起草，再人工修正。
    4. 
      
  4. 「训练」页选模型与设备，开始后实时显示日志和曲线。

      
模型与数据

      
  1. 「模型管理」的权重清单实时取自官方仓库，点「刷新在线模型」可拉取最新版本。
    2. 
      
  2. 自行下载的 .pt / .onnx 权重，用「导入本地权重」选择文件即可加入模型库。
    3. 
      
  3. 离线时自动回退到内置模型列表，不影响使用。
