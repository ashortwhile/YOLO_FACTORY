第一次使用

  1. 双击 YOLO工坊-安装版.exe 完成安装，再点桌面图标启动；首次运行会自动探测显卡、创建独立虚拟环境，并下载匹配的最新版 PyTorch / Ultralytics 与默认权重（需联网，几分钟）。
  2. 安装版启动后直接弹出独立应用窗口；绿色版请保持黑色控制台窗口开着，它是本地服务。
  3. 「数据集」页新建数据集，或挂载 / 扫描已有的 YOLO 目录（软件默认不预置任何数据）。
  4. 「打标签」页人工画框；点「AI 预标注」可用已有权重起草，再人工修正。
  5. 「训练」页选模型与设备，开始后实时显示日志和曲线。

常见问题

Q：显存容量显示不准？
Windows 的 WMI 显存字段是 32 位，大显存显卡容易显示错误；本软件改读注册表的 64 位数值，显示真实容量。

Q：训练时报字体下载错误？
软件已默认关闭字体下载与绘图（plots=False），不会触发该问题。

Q：首次启动没装上显卡后端？
多为离线或下载源不可达；联网后重新启动会自动补齐，也可在「环境与显卡」页手动切换，失败会自动回退 CPU。

Q：只能跑 CPU？
纯 CPU 时建议 yolo26n + batch 1 + imgsz 512；YOLO26n 针对 CPU 推理做了优化。

Q：预标注类别不对？
COCO 预训练权重只有 80 个通用类别，与自定义类别不匹配；软件会把它当作「候选框」，统一设为指定类别，请人工改。用自己训好的权重预标注才带正确类别。

Q：模型下载失败？
软件会先走国内可访问的镜像源，再回退官方源。仍失败时可用「导入本地权重」或「自定义下载地址」，也可以直接把 .pt 放进 workspace/models；或者直接选 yolo26.yaml 从零训练，完全不需要权重文件。
